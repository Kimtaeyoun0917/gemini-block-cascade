# 모바일 테트리스

휴대폰에서 손가락으로 바로 즐기는 테트리스입니다. HTML 파일 하나로 동작해서 설치할 것이 없습니다.

## 바로 플레이

**공유 링크:** https://kimtaeyoun0917.github.io/gemini-block-cascade/tetris/

위 주소를 카카오톡·문자로 보내면 받은 사람이 자기 휴대폰 브라우저에서 바로 게임할 수 있습니다.

## 조작 방법

화면 아래 버튼을 눌러도 되고, 게임판 위에서 손가락으로 쓸어도 됩니다.

| 동작 | 버튼 | 게임판 제스처 |
| --- | --- | --- |
| 왼쪽 / 오른쪽 이동 | ◀ 왼쪽 / 오른쪽 ▶ | 좌우로 쓸기 |
| 한 칸 내리기 | ▼ 내리기 | 아래로 쓸기 |
| 시계 / 반시계 회전 | ↻ 시계 / ↺ 반시계 | 톡 누르기(시계 방향) |
| 즉시 떨어뜨리기 | ⤓ 즉시 | 위로 쓸기 |
| 블록 보관 | HOLD | — |

오른쪽 위 버튼으로 효과음을 켜고 끄거나 일시정지할 수 있습니다.

## 게임 기능

- 다음 블록 미리보기, HOLD(블록 보관)
- 바닥에 닿을 위치를 보여 주는 고스트 표시
- 콤보 보너스, 레벨에 따라 빨라지는 낙하 속도
- 바닥에 닿은 뒤 0.45초 동안 밀어 넣을 수 있는 여유 시간
- 최고 점수는 브라우저에 저장되어 다시 열어도 남아 있습니다

## 파일 구성

- `index.html` — 게임 전체(화면·디자인·동작이 모두 이 한 파일에 들어 있음)
- `README.md` — 이 설명 문서

## GitHub 웹에서 직접 수정하는 방법

1. https://github.com/Kimtaeyoun0917/gemini-block-cascade/tree/main/tetris 접속
2. 목록에서 `index.html` 클릭
3. 오른쪽 위 **연필 모양 아이콘**(Edit this file) 클릭
4. 내용을 고친 뒤 오른쪽 위 **Commit changes** → 다시 **Commit changes**
5. 1~2분 뒤 공유 링크를 새로고침하면 수정한 내용이 반영됩니다.

휴대폰 GitHub 앱에서도 같은 순서로 고칠 수 있습니다(저장소 → `index.html` → 연필 아이콘).

## 수정할 때 참고

- 게임의 색·크기: `index.html` 위쪽 `<style>` 안의 `:root` 값(배경색, 강조색 등)
- 블록 모양과 회전: `SHAPES` 객체
- 점수 계산·레벨 속도: `clearLines`, `dropInterval` 근처 코드
- 수정 후 문제가 생기면 GitHub의 **History**(파일 화면 오른쪽 위 시계 아이콘)에서 이전 버전을 확인할 수 있습니다.
